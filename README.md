# Kırmızı Işıkla Barış Antlaşması

## 1. Taraflar

Bir tarafta **Siz** (bundan böyle "Yaya / Sürücü / Sabırsız Vatandaş"),

diğer tarafta **Kavşaktaki Kırmızı Işık** (bundan böyle "Karşı Taraf", "Işık Bey" veya "Devletin En Kısa Ama En İnatçı Memuru").

## 2. Amaç

Bu yazılım, kırmızı ışıkla savaşmak yerine **müzakere etmek** için tasarlanmıştır. Yeşil yanana kadar kornaya basmak tarih olmuştur. Artık protokol vardır. Protokolün kendisi de biraz yorulmuştur.

## 3. Kurulum

```bash
python3 muzakere.py
```

Bağımlılık yoktur. Sadece standart kütüphane ve biraz gurur.

## 4. Nasıl Çalışır

1. Program Işık Bey'e resmi nota gönderir.
2. Işık Bey cevap vermez (klasik).
3. Program bekleme süresini "ulusal güvenlik" gerekçesiyle rastgele uzatır.
4. Sonunda bir taraf teslim olur. Genelde siz. Nadiren ışık. Çok nadiren evren.

## 5. Bilimsel Dayanak

Bekleme süresi aşağıdaki formülle hesaplanır:

`saniye = 3 + (sabirsizlik * komsunun_kornasi) / cay_sicakligi`

Formül hakem onaylıdır. Hakem çaydadır.
